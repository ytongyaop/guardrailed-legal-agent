# 基线快照说明

这些文件冻结 v0.3.2 的领域输出与 Word 报告文本，供 0.4.0 前后端比对。

## 何时需要重录

只有以下情况可以重录，且必须单独提交、在提交说明里写明原因：

1. 判定逻辑按规格正式变更（`docs/design/003` 或 `005` 更新）
2. 法源库、规则表、触发器表按规格更新（如补触发器）
3. 报告模板按产品要求变更

**不允许**为了让某个红色断言变绿而重录。重录后必须人工核对差异，确认差异都来自上述变更。

## 怎么重录

```bash
python tests/api/fixtures/build_tasks.py
```

会重写 `*.snapshot.json` 与 `*.report.txt`。跑完用 `git diff` 逐份看差异。

## 已知的既有缺陷（照抄未修）

- 报告里「可判定 / 不适用 / 无法判定」三个数相加大于总数：`judged` 把 `not_applicable` 也算进"可判定"。属 v0.3.2 既有口径，修它属判定变更，需单独评估。
- `rule_check` 条目的 `kind`（待确认）与 `certainty`（确定冲突）语义不一致。前端以 `certainty` 为准分组展示，不要用 `kind`。

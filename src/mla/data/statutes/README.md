# 法源条目（statutes.jsonl）

一行一条 JSON，对应 `mla.domain.models.StatuteEntry`。
来源只取官方：国家法律法规数据库 / 中国政府网 / 人社部 / 最高法。

## 字段口径（2026-11-03 复核后确定）

| 字段 | 口径 | 说明 |
|---|---|---|
| `statute_id` | `法简写-条号` | 如 `LCL-19`；前缀约定见 `source_kind()` |
| `text` | **条文原文逐字** | 含各款，标点全角；由 `scripts/validate_statutes.py` 与官方快照逐字比对 |
| `effective_date` | **现行版本施行日** | 如劳动合同法填 2013-07-01（2012 修正施行日），不是 2008-01-01 |
| `doc_no` | **现行版本对应的修正/修订令** | 如劳动合同法填“主席令第七十三号”，不是原公布令 |
| `status` | 有效 / 失效 / 被替代 | 现行版本均为有效 |
| `note` | 补充说明 | 记“部分废止”等无法用 status 表达的例外，如 `J1-32` 第一款已被解释（二）第 21 条废止 |
| `region` | 全国 | 地方性法源暂不收录 |

## 收录范围

只收**与合同条款判定直接相关**的条文，不做全库。当前 143 条 / 12 部：

劳动合同法 · 实施条例 · 劳动法 · 最高法解释（一）（二）· 调解仲裁法 · 社会保险法 ·
工伤保险条例 · 工资支付暂行规定 · 年休假条例 · 年休假实施办法 · 放假办法

## 校验

```
python scripts/validate_statutes.py src/mla/data/statutes/statutes.jsonl
```

逐字比对需要官方原文快照，可通过 `--snapshot-dir` 指定快照根目录（按法源前缀分子目录）；
未提供时只做结构与条数校验。

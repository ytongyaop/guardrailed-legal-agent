# 隐私说明

本程序在你自己的电脑上运行，页面地址是 127.0.0.1，只绑定本机回环地址，局域网里的其他设备访问不到。分析合同需要调用你自己配置的大模型服务，因此合同文本会从你的电脑**直接发送到模型服务商，不经过项目作者的任何服务器——我们看不到你的合同**。

| 问题 | 答案 |
| --- | --- |
| 合同正文去哪了 | 发送到你自己配置的模型服务商（大模型，以及可选的向量检索服务）；只有你点击“开始核对”后才会发送，程序不会在后台自动上传 |
| 本机存了什么 | 账号、企业信息、合同、核对记录，都在 `%LOCALAPPDATA%\mla\mla.sqlite3` |
| API Key 存哪 | 在 `%LOCALAPPDATA%\mla\auth.json`，只保存在本机，界面上不回显完整 Key，也不会上传给项目作者 |
| 有没有统计或遥测 | 没有。程序不收集使用数据，不做崩溃回传，不向项目作者回传任何信息 |
| 怎么清除数据 | 删除整个 `%LOCALAPPDATA%\mla\` 目录即可；也可以先在设置页清除已保存的 Key |
| 怎么备份或迁移 | 复制 `%LOCALAPPDATA%\mla\` 目录到新电脑的同一路径即可，账号、合同与历史记录都在里面 |

## 发送给服务商的具体内容

- 信息抽取环节会发送合同正文，单次上限 20000 字（默认设置）。
- 条款审查环节不发送合同全文，只发送被标记为可疑的候选条款及其前后各 2 行邻近段落；姓名、住址、身份证号、工资数额等无关段落不会随条款审查发出。
- 配置了阿里云百炼向量服务时，检索请求只发送以下两类内容之一：问答场景发送你的问题原文；核对场景发送从合同中抽出的结构化要素（例如“合同期限：三年”“试用期：十二个月”），不含合同正文。不配置该 Key 时检索自动回退为本地关键词匹配，完全离线。
- 发送出去的内容如何留存、是否用于训练，以模型服务商（DeepSeek、阿里云百炼）自己的隐私政策为准，本项目无法控制，建议先阅读服务商的相关条款。

## 本地文件的安全

`auth.json` 中的 API Key 以明文保存，但文件权限已收紧为仅当前 Windows 用户可读。请不要把这个文件（或整个 `mla` 目录）复制给他人或提交到任何仓库。删除该目录后，账号与历史记录无法恢复。
